## Overview

Designed and developed a real-time industrial monitoring platform focused on turbine operations and energy generation visualization.
The project involved transforming legacy Excel-style monitoring interfaces into a modern, interactive dashboard system capable of displaying critical operational data in real time.
The platform was tailored for different user roles and optimized for monitoring complex industrial processes through data visualization and 3D interactions.
My role covered both UX/UI design and front-end implementation using Angular, including component development, responsive layouts, and custom styling.

## Key Features

- **Real-Time Turbine Monitoring**

Designed a live monitoring dashboard that displayed operational turbine metrics such as power output, speed, vibration, pressure, efficiency, and thermal data.
The interface was structured to prioritize critical information and allow operators to quickly identify abnormal values or operational alerts in real time.

- **Interactive 3D Turbine Visualization**

Created an interactive 3D turbine model using Three.js that allowed users to inspect different turbine sections visually.
Each component included contextual labels and live operational data, helping technical users understand turbine behavior and component performance directly from the interface.

- **Power Plant Flow Visualization**

Designed a 3D visualization representing the complete energy generation process inside the plant.
The dashboard illustrated how energy and steam moved through turbines, transformers, and other operational systems, including flow direction, speed, and output indicators, providing a more intuitive understanding of the plant infrastructure.

- **Role-Based Dashboards**

Developed customized dashboard experiences adapted to different user profiles and responsibilities.
Each user type had access to different KPIs, widgets, and monitoring priorities, improving usability and reducing unnecessary information overload.

- **Transition from Legacy Interfaces**

Redesigned outdated spreadsheet-style interfaces into a modular dashboard system with clear visual hierarchy, structured navigation, and interactive data visualization.
The new experience improved readability, operational awareness, and interaction efficiency compared to the previous static interfaces.

## Technologies Used

- **Angular**

Used Angular to build modular and scalable front-end architecture for the dashboard system.
Developed reusable UI components and dynamic interfaces optimized for real-time data visualization.

- **Three.js**

Implemented interactive 3D visualizations for turbines and plant infrastructure.
Three.js enabled real-time rendering of operational models and interactive exploration of complex industrial systems directly within the browser.

- **TypeScript**

Used TypeScript to improve code scalability, maintainability, and component structure across the application.
Helped manage complex dashboard logic and data interactions more efficiently.

- **HTML5 & CSS3**

Built responsive layouts and custom UI styling optimized for high-density industrial dashboards.
Focused on visual hierarchy, readability, and usability across different screen sizes and operational environments.

- **Figma**

Used Figma for UX flows, dashboard wireframes, component design, and interface prototyping.
Helped align visual structure, interaction patterns, and front-end implementation before development.
