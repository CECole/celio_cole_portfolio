## Overview

Designed and developed a responsive event calendar platform for a nightclub and artist tour management website.
The project focused on redesigning the event experience for both desktop and mobile users, improving usability, event discoverability, and navigation across multiple event types, venues, and artist tours.
The original calendar interface worked correctly on desktop but failed on mobile devices, where event information, dates, and schedules became difficult to read and navigate. The redesign introduced flexible calendar views, filtering systems, and CMS-driven dynamic content management.
My role included UX research, UI design, user testing, Webflow implementation, JavaScript interactions, and responsive front-end customization.

## Key Features

- **Figma Plugin Integration**
Developed a custom Figma plugin that extracts design tokens such as colors, typography, and spacing values, and exports them in a format compatible with our codebase.

- **Responsive Event Calendar Redesign**
Redesigned the existing event calendar into a fully responsive experience optimized for both desktop and mobile devices.
The new interface improved readability of dates, event cards, and schedules across different screen sizes, solving the usability issues present in the previous version.

- **Multiple Calendar Views**

Implemented different event visualization modes depending on user preference and device context.

Users could switch between:
Grid-based calendar layouts.
List-based views with one event per row.

This flexibility improved event scanning and navigation, especially on smaller mobile screens.

- **Dynamic CMS Integration**

Built the calendar system using CMS-driven content injection through Webflow.
Events, artist tours, venues, and schedules could be dynamically updated without manual interface modifications, allowing content managers to maintain the platform efficiently.

- **Event Filtering System**

Designed filtering interactions that allowed users to quickly navigate between:
Nightclub events.
Artist tours.
Specific venues or rooms.
Event dates.
City-based tour locations.

The filtering system reduced navigation friction and improved event discoverability.

- **Mobile UX Optimization**

Focused heavily on mobile-first usability improvements.

Optimizations included:
Simplified navigation.
Adaptive layouts.
Touch-friendly interactions.
Improved spacing and typography.
Clearer event hierarchy.

This significantly improved the mobile browsing experience compared to the original calendar.

- **User Testing & Iteration**

Conducted multiple usability testing sessions to validate navigation flows, calendar readability, and filtering interactions.

Feedback from users was used to iterate on:
Event card hierarchy.
Date visibility.
Filtering behavior.
Mobile navigation patterns.

## Technologies Used

- **Webflow**

Used Webflow as the primary platform for building and managing the website structure and CMS integration.
Enabled rapid iteration, responsive layout management, and dynamic content publishing for events and artist tours.

- **JavaScript**

Implemented custom interactions and calendar behaviors using JavaScript.
This included filtering logic, dynamic view switching, and interactive event navigation enhancements.

- **CMS Integration**

Configured CMS collections to dynamically manage:
Events.
Venues.
Artist tours.
City schedules.
Calendar updates.

This allowed non-technical users to update event information directly from the CMS.

- **HTML5 & CSS3**

Developed responsive layouts and custom styles optimized for event-heavy interfaces across desktop and mobile devices.
Focused on readability, visual hierarchy, and adaptive layouts.

- **Figma**

Used Figma for UX flows, wireframes, responsive layouts, and UI component design before implementation.

## Challenges and Learnings

- **Challenges**
Redesigning a calendar system that worked poorly on mobile devices.
Managing large volumes of dynamic event data across multiple views.
Creating flexible filtering systems without increasing interface complexity.
Balancing visual density with usability in event-heavy interfaces.

- **Learnings**
Improved understanding of responsive UX patterns for event platforms.
Learned how to optimize calendar experiences for mobile-first interaction
Strengthened skills in CMS-driven interface design.
Gained experience combining Webflow with custom JavaScript interactions.

## Outcome

Successfully redesigned the calendar into a fully responsive experience.
Improved visibility and readability of events across all devices.
Reduced friction in event navigation and discovery.
Enabled dynamic management of events and artist tours through CMS integration.
Delivered a more scalable and user-friendly event browsing experience.
