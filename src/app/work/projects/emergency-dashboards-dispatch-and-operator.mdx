## Overview

Designed and developed a centralized emergency management platform for C5 operations focused on real-time incident monitoring and dispatch coordination.
The existing system relied on multiple disconnected windows for cameras, reports, evidence, and emergency details, creating fragmented workflows and slowing down critical decision-making processes.
The project involved redesigning the experience into role-based operational dashboards for operators and dispatchers, improving efficiency, context visibility, and incident management workflows.
My role included UX/UI design, workflow architecture, front-end component development in Angular, and CSS implementation.

## Key Features

- **Operator Dashboard**

Designed a centralized operational dashboard that allowed operators to manage incidents from a single interface.
Users could monitor emergency details, access live camera feeds, update reports, and track ongoing incidents without switching between multiple windows.

- **Dispatcher Dashboard**

Created a dedicated dashboard optimized for dispatch coordination and resource management.
The interface allowed dispatchers to assign units, monitor active emergencies, prioritize incidents, and track operational responses in real time.

- **Integrated Incident View**

Developed a unified incident management interface where cameras, maps, reports, evidence, and incident details were displayed within the same workflow.
This reduced context switching and improved decision-making speed during emergencies.

- **Progressive Incident Updates**

Designed interaction flows that allowed operators to continuously add new information during active incidents, such as suspect descriptions, evidence, or updated emergency details.
The workflow supported fast data entry while maintaining operational continuity.

- **Modular Navigation System**

Created a modular navigation structure using tabs, contextual icons, and reusable interface components.
The system improved navigation efficiency and allowed users to quickly access critical information in high-pressure operational scenarios.

## Technologies Used

- **Angular**

Used Angular to build dynamic dashboards and reusable operational components.
Enabled scalable interface management and efficient handling of real-time emergency data.

- **TypeScript**

Implemented TypeScript to structure application logic and improve maintainability across complex workflows and UI states.

- **RxJS**

Used RxJS to manage reactive data flows and asynchronous updates related to emergency events, camera feeds, and operational status changes.

- **HTML5 & CSS3**

Developed responsive and high-density dashboard layouts optimized for operational environments.
Focused on usability, readability, and fast interaction under pressure.

- **Figma**

Used Figma to design workflows, wireframes, dashboard layouts, and reusable interface components before implementation.
